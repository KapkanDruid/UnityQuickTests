# История изменений

[![Read in English](https://img.shields.io/badge/Read_in_English-blue)](CHANGELOG.md)

## Невыпущенные изменения

- Добавлены английская и русская версии всей публикуемой документации, кнопки переключения языка и ссылки на документы на соответствующем языке.

## 1.1.2

- README переработан с акцентом на практическую задачу, которую решает Unity Quick Tests.
- Упрощены описания ограничений и диагностики для пользователей.
- Завершённые планы развития и заметки о проектировании перенесены из версионируемой документации в локальные материалы; инструкция по тестированию оставлена в Git.

## 1.1.1

- Добавлено меню `Tools/Unity Quick Tests/Warning Settings` для включения и отключения предупреждений Unity Quick Tests.
- Добавлены предупреждения с проверками условий для методов с параметрами и целей вызова, оказавшихся равными null.
- В отчёт о зарегистрированных проверках добавлены сигнатуры методов.
- Сборки тестов пакета исключены из поиска методов во время работы, чтобы тестовые классы пакета не появлялись в списках зарегистрированных проверок потребительских проектов.
- Исправлен момент запуска `QuickTestSchedule`: методы по расписанию теперь ждут заданный интервал, а не вызываются сразу после перезагрузки.
- Расписания методов экземпляра отложены до появления живой цели; отсчёт интервала начинается при её появлении, а предупреждения об отсутствии цели во время ожидания подавляются.
- Обновлены примеры установки с учётом переименования репозитория GitHub.

## 1.0.0

- Лицензия пакета изменена на MIT.
- Добавлен план развития возможностей на русском языке.
- Добавлены тестовый host-проект в Git, скрипт запуска в batchmode и базовые автоматические тесты.
- Добавлена инструкция по тестированию на русском языке.
- Добавлен вызов quick-test методов на живых экземплярах `MonoBehaviour`, `ScriptableObject` и `EditorWindow`.
- Добавлен реестр со слабыми ссылками для экземпляров обычных C#-классов.
- Добавлена автоматическая регистрация в поддерживаемых конструкторах обычных C#-классов через IL PostProcessor, работающий только в редакторе.
- Добавлены smoke-проверки безопасности player build: отсутствие кода Editor/CodeGen, исключение скрытого объекта опроса ввода и проверка внедрённых вызовов регистрации.
- Добавлена диагностика в редакторе для зарегистрированных проверок, области поиска и статуса целей, конфликтов горячих клавиш и отсутствующих целей.
- Определены границы расширения API для наследуемых, обобщённых, асинхронных методов и методов с параметрами, выбора целей и новых способов запуска.

## 0.1.0

- Добавлен `QuickTestHotkeyAttribute` для вызова статических quick-test методов в редакторе и в Play Mode.
- Добавлен `QuickTestScheduleAttribute` для запуска по расписанию в тиках обновления редактора или секундах.
- Добавлены поиск методов в редакторе, выполнение расписаний, обработка событий Scene View и опрос ввода в Play Mode.
